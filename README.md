# My Awesome Future 未來英雄圖鑑

國小三年級英語職業單字互動教學網頁。單一 HTML 檔、**完全離線可用**，不需網路、不需安裝。

👉 **線上版**：https://hsieny627-jpg.github.io/my-awesome-future/

## 教什麼

| 項目 | 內容 |
|---|---|
| 職業單字 | 10 個 |
| 句型 | `I am a ___ ___.` / `I want to be a ___.` |
| 核心規則 | **動作 ＋ -er ＝ 做這件事的人** |

## 八個關卡

1. **開場** — 2035 年的我
2. **說明書** — 紅字＝超能力；`to` 是隱形小精靈，不翻譯
3. **-er 魔法** — `bake` ＋ `er` 合體成 `baker` 的動畫，含 `-or`／`-ian` 兩個兄弟字尾
4. **職業圖鑑** — 10 張卡，每張含逐字飛入的句子、秒懂中英對照表、音節拆解、記憶鉤
5. **句型工廠** — 自由搭配形容詞與職業造句
6. **密碼遊戲** — 🎧＋💻＋💰＝？
7. **水晶球** — 讀心術猜職業
8. **未來 ID 卡** — `I want to be a ___.`

## 上課用法

| 功能 | 說明 |
|---|---|
| 點任何英文字 | 慢速念出該字 |
| 🔊 整句慢慢念一次 | 整句朗讀，**唸到哪個字，那個字就亮起來** |
| 音節方塊 | 可單獨點讀；**紅色＝母音字母，灰色＝不發音** |
| ◀ ▶ | 句子左右兩側，快速切換上一句／下一句 |
| 語速拉桿 | 0.40× ～ 1.20×（預設 0.75×） |
| 對齊拉桿 | 調整打光與聲音的同步（預設 −275 ms） |
| 🔊 / 🔇 | 靜音後動畫照常播放 |
| F11 | 全螢幕投影 |

### 對齊拉桿怎麼調

瀏覽器回報「正在唸第幾個字」的時間，和喇叭真正出聲的時間有落差，每台電腦不同。

- 字比聲音**先亮** → 往「晚」拉
- 字比聲音**慢半拍** → 往「早」拉

調一次就好，設定會自動記住。

### 發音沒聲音時

需要系統安裝英語語音。Windows：**設定 → 時間與語言 → 語言與地區 → 新增語言 → English (United States)**，安裝時勾選文字轉語音。
